# accounts/ - регистрация и доступы

Моделей нет: используется стандартный `auth.User` Django.

- `/accounts/signup/` - открытая регистрация (`UserCreationForm`): после
  создания аккаунта пользователь сразу входит;
- `/accounts/login/` и `/accounts/logout/` - штатные представления Django
  (`config/urls.py`), страница входа ссылается на регистрацию;
- у каждого пользователя только свои данные: владелец проставлен во всех
  моделях (категории, бюджетные месяцы, траты, планы покупок), выборки
  фильтруются по `request.user`, чужой pk отвечает 404;
- обычный пользователь не имеет доступа в админку: `/admin/` - только
  для staff (владелец сервера).

Тесты - `accounts/tests.py`.
