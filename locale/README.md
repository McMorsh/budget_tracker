# locale/ - переводы

Интерфейс русский (`LANGUAGE_CODE = ru`, форматы ru-RU), поэтому здесь живут
переводы строк и заготовка на случай добавления языков.

Файлы: `ru/LC_MESSAGES/django.po` -> `django.mo`
(`django-admin makemessages -l ru`, затем `compilemessages`).

Пока каталог пуст: свои строки уже на русском; переводы понадобятся,
только если добавятся другие языки.
