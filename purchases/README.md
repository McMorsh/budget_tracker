# purchases/ — планы покупок

Модели:
- `PlannedPurchase` — цель: название, стоимость, приоритет, статус
  (хочу / коплю / куплено); прогресс считается из взносов;
- `PurchaseContribution` — взнос в цель: сумма, дата, комментарий.

Страница планов покупок — Фаза 8. Возможная связь с суммой «отложить» из
месячного распределения — открытый вопрос, см. `PLAN.md`.
