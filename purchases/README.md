# purchases/ — планы покупок

Модели:

- `PlannedPurchase` — цель: название, стоимость, приоритет, статус
  (хочу / коплю / куплено); прогресс считается из взносов, дата покупки
  проставляется при переводе в «куплено» и снимается при возврате;
- `PurchaseContribution` — взнос в цель: сумма, дата, комментарий.

Экраны:

- `/purchases/` — список: форма добавления, активные цели с прогрессом
  (двойной клик по строке — инлайн-правка), отдельная таблица «Куплено».
  Активные цели — по приоритету (больше число — выше), затем по дате
  создания (сначала новые); «Куплено» — по дате покупки (сначала новые);
- `/purchases/<pk>/` — карточка цели: прогресс, форма взноса, список взносов
  (инлайн-правка и удаление), удаление цели каскадом.

Смена статуса: при добавлении цели, в редакторе строки (двойной клик) и
кнопками «Куплено»/«Вернуть» (они же проставляют и снимают дату покупки).
JSON-эндпоинты (`purchase_update`, `purchase_status`, `contribution_update`)
после сохранения перезапрашивают разметку с сервера, поэтому прогресс и
итоги всегда совпадают с базой.

Связь с суммой «отложить» из месячного распределения пока не реализована —
возможно, сделаем позже.
