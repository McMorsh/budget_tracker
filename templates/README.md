# templates/ — HTML-шаблоны

- `base.html` — общий каркас: меню, сообщения, футер;
- `home.html` — обзорная страница (текущий месяц, цели покупок);
- `coming_soon.html` — заглушка разделов до их фаз;
- `registration/login.html` — страница входа;
- подпапка на каждое приложение по мере роста: `budget/`, `expenses/`,
  `purchases/`, `reports/` (включая шаблон PDF-отчёта в Фазе 7).

Правило: шаблоны только отображают данные, вся логика — во вьюхах и моделях.
