# expenses/ - ежедневные траты

Модели:
- `Transaction` - трата: дата, категория, сумма, комментарий.

Правила:
- месяц траты вычисляется из даты (`timezone.localdate()`), отдельного поля
  "месяц" нет; выборки - в `expenses/queries.py` (`transactions_for_month`,
  `transactions_for_period`);
- сумма ≥ 0,01 ₽ - `MinValueValidator` на модели + CheckConstraint в БД;
- траты принадлежат владельцу (`owner`): выборки, форма и JSON-эндпоинты
  работают только с данными залогиненного пользователя, чужая трата -> 404;
- перерасход плана категории: при вводе и правке траты показываем
  предупреждение, если план в рублях больше нуля и факт его превысил;
  трата при этом сохраняется;
- категория защищена от удаления (`PROTECT`) - история трат сохраняется.

Экраны:
- `/expenses/` и `/expenses/<год>/<месяц>/` - форма быстрого ввода
  (сумма, категория, дата, комментарий) и список трат месяца с итогом;
- дата по умолчанию: текущий месяц - сегодня, прошедший - последний день,
  будущий - первое число; месяц сохранения определяется датой;
- добавление и удаление - обычные POST с редиректом (PRG); правка строки -
  инлайн (двойной клик или "Изменить") через JSON-эндпоинт
  `transaction_update`, после чего таблица перезапрашивается с сервера
  (`static/js/expenses.js`), чтобы порядок строк и итоги совпадали с БД;
- архивные категории в истории видны с пометкой, для новых трат не
  предлагаются.

Данные участвуют в сводке "план/факт" и в PDF-отчёте.
