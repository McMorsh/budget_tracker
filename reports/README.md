# reports/ — аналитика и отчёты

Приложение без собственных моделей: только расчёты и отображение.

- `home` — обзорная страница: текущий месяц и цели покупок (Фаза 2);
- сводка «план/факт» по категориям за месяц (Фаза 6);
- графики Chart.js: месяц, год, динамика (Фаза 6);
- PDF-отчёт за месяц через WeasyPrint (Фаза 7), готовые файлы — в `media/`.
