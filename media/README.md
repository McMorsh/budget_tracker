# media/ - генерируемые файлы (не в git)

Сюда складываются создаваемые приложением файлы: PDF-отчёты за месяц и т.п.

- Содержимое исключено из git (см. `.gitignore`), отслеживается только этот
  README.
- PDF-отчёты лежат в `media/reports/<id пользователя>/` (`<год>-<месяц>.pdf`
  и `<год>.pdf`) и пересобираются при каждом скачивании.
- Публичной раздачи `media/` нет ни в dev, ни в проде: файлы отчётов
  у каждого пользователя свои (`media/reports/<id>/`), их отдаёт Django
  только владельцу; маршрута `/media/` в роутинге нет.
- На сервере папка лежит на диске и попадает в бэкапы вместе с базой
  (`pg_dump` + media).
- Личные данные из `media/` не публикуются.
