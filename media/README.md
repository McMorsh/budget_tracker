# media/ — генерируемые файлы (не в git)

Сюда складываются создаваемые приложением файлы: PDF-отчёты за месяц и т.п.

- Содержимое исключено из git (см. `.gitignore`), отслеживается только этот
  README.
- PDF-отчёты лежат в `media/reports/` (`<год>-<месяц>.pdf` и `<год>.pdf`)
  и пересобираются при каждом скачивании.
- В разработке `media/` раздаёт runserver без проверки входа (DEBUG), поэтому
  не открывайте dev-сайт в общую сеть; в продакшене доступ закрывает Caddy
  (Фаза 9).
- На сервере папка лежит на диске и попадает в бэкапы вместе с базой
  (`pg_dump` + media).
- Личные данные из `media/` не публикуются.
